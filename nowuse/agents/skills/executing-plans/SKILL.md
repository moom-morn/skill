# 执行计划

## 概述

加载计划，严格审阅，执行所有任务，完成后报告。

**开始时声明：** "我将使用 executing-plans 技能来执行这个计划。"

**注意：** 告诉你的用户伙伴，Superpowers 在有子代理访问权限时表现更好。如果在支持子代理的平台上运行（如 Claude Code 或 Codex），工作质量会显著提高。如果子代理可用，使用 superpowers:subagent-driven-development 而不是此技能。

## 流程

### 第一步：加载并审阅计划

1. 读取计划文件
2. 严格审阅——识别对计划的任何问题或疑虑
3. 如有疑虑：在开始之前向你的用户伙伴提出
4. 如无问题：创建 TodoWrite 并开始执行

### 第二步：执行任务

对每个任务：

1. 标记为 in_progress
2. 精确遵循每一步（计划包含颗粒度的步骤）
3. 按指定方式运行验证
4. 标记为 completed

### 第三步：完成开发

所有任务完成并通过验证后：

-   声明："我将使用 finishing-a-development-branch 技能来完成这项工作。"
-   **必需的子技能：** 使用 superpowers:finishing-a-development-branch
-   遵循该技能来验证测试、呈现选项、执行选择

## 何时暂停并寻求帮助

**遇到以下情况立即停止执行：**

-   遇到阻塞（缺少依赖、测试失败、指令不清晰）
-   计划有严重空缺，无法开始
-   理解不了某个指令
-   验证反复失败

**寻求澄清，不要猜测。**

## 何时回退到之前的步骤

**回到审阅（第一步）：当：**

-   你的伙伴根据你的反馈更新了计划
-   基本方案需要重新思考

**不要强行冲破阻塞**——停下来问。

## 牢记

-   先严格审阅计划
-   精确遵循计划步骤
-   不要跳过验证
-   当计划要求时引用技能
-   遇到阻塞时停下来，不要猜测
-   未经用户明确同意，绝不在远程分支上开始实现，仅有本地的代码修改权限，禁止自动使用 git

## 集成

**必需的流程技能：**

-   **superpowers:using-git-worktrees** — 确保隔离的工作空间（创建一个或验证已有的）
-   **superpowers:writing-plans** — 创建此技能要执行的计划
-   **superpowers:finishing-a-development-branch** — 所有任务完成后完成开发
