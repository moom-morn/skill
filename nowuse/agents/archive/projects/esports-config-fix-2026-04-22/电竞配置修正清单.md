# 电竞配置修正清单

**紧急修正项：** search 参数值错误

---

## 问题诊断

### 当前配置的错误

在以下4个文件中发现 search 参数使用不标准的值：

```
❌ /src/components/newMySearch/components/searchKey/compKey/matchBall/lol.js
❌ /src/components/newMySearch/components/searchKey/compKey/matchBall/csgo.js
❌ /src/components/newMySearch/components/searchKey/compKey/matchBall/dota.js
❌ /src/components/newMySearch/components/searchKey/compKey/matchBall/kog.js
```

### 错误值汇总

```javascript
search: "queryTournament"   // ❌ 应该是 "competition"
search: "queryStage"        // ❌ 应该是 "stage"
search: "queryTeam"         // ❌ 应该是 "team"
search: "queryHero"         // ❌ resourceTextJump中无定义 → 删除 + 用opts
search: "queryEquipment"    // ❌ resourceTextJump中无定义 → 删除 + 用opts
search: "queryItem"         // ❌ resourceTextJump中无定义 → 删除 + 用opts
search: "queryMap"          // ❌ resourceTextJump中无定义 → 删除 + 用opts
search: "queryWeapon"       // ❌ resourceTextJump中无定义 → 删除 + 用opts
```

---

## 修正方案

### 方案1：快速修正（推荐）
直接替换search值，删除无定义的字段

#### lol.js 修正

```javascript
// 将这些：
search: "queryTournament"   →  search: "competition"
search: "queryStage"        →  search: "stage"
search: "queryTeam"         →  search: "team"

// 删除这些整个搜索配置，改用opts：
// 删除：search: "queryHero"
// 改为：opts: [{label: '盲僧', value: 1}, ...]
```

#### csgo.js 修正

```javascript
// 替换
search: "queryTournament"   →  search: "competition"
search: "queryStage"        →  search: "stage"
search: "queryTeam"         →  search: "team"

// 删除并改用opts
search: "queryMap"
search: "queryWeapon"
```

#### dota.js 修正

```javascript
// 替换
search: "queryTournament"   →  search: "competition"
search: "queryStage"        →  search: "stage"
search: "queryTeam"         →  search: "team"

// 删除并改用opts
search: "queryHero"
search: "queryItem"
```

#### kog.js 修正

```javascript
// 替换
search: "queryTournament"   →  search: "competition"
search: "queryStage"        →  search: "stage"
search: "queryTeam"         →  search: "team"

// 删除并改用opts
search: "queryHero"
search: "queryItem"
```
