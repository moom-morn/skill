# 强制刷新弹框方案

## 版本检测原理

Vue CLI 构建后 `index.html` 中 `<script>` 的 src 含内容 hash（如 `js/app.a1b2c3d4.js`）。每次发版 hash 变化，前端定时拉取 `index.html` 比对即可感知更新。

```mermaid
flowchart LR
    appMount["App 挂载"] --> fetchInit["首次获取 index.html\n提取 script hash"]
    fetchInit --> timer["每 5 分钟轮询"]
    timer --> fetchNew["重新获取 index.html\n(加 timestamp 防缓存)"]
    fetchNew --> compare{hash 是否变化}
    compare -->|否| timer
    compare -->|是| showDialog["弹出强制刷新弹框"]
    showDialog --> click["用户点击「立即刷新」"]
    click --> reload["window.location.reload()"]
```

## 各文件关键内容

### `src/utils/versionCheck.js`
- `extractHash(html)`：用正则从 html 字符串中提取所有 `<script src="...">` 的路径，拼成指纹字符串
- `startVersionCheck({ interval, onUpdate })`：记录初始 hash，setInterval 定时 fetch，触发 `onUpdate` 回调
- `stopVersionCheck()`：清除 timer，用于页面卸载
- 轮询 URL：`window.location.origin + '/?t=' + Date.now()`（cache-busting）

### `src/components/ForceRefreshDialog/index.vue`
- `el-dialog` 配置：`:visible.sync` 但不允许关闭（`:close-on-click-modal="false"` `:close-on-press-escape="false"` `:show-close="false"`）
- 遮罩 z-index 设为 `9999` 确保覆盖所有内容
- 显示提示文案：「系统已更新，请刷新页面以继续使用」
- 按钮：「立即刷新」→ `window.location.reload()`

### `src/App.vue`
- 引入 `ForceRefreshDialog` 和 `startVersionCheck`
- `data` 添加 `showRefreshDialog: false`
- `mounted` 中调用 `startVersionCheck({ interval: 5 * 60 * 1000, onUpdate: () => { this.showRefreshDialog = true } })`
- 模板中添加 `<ForceRefreshDialog :visible="showRefreshDialog" />`
