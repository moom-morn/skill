# 对阵图点击编辑规则

## 需求
- 16强上 (index 15-22) 和 16强下 (index 23-30)：点击弹出选人弹窗（可选人 + 改票数）
- 8强/4强/冠军等其余位置：点击弹出仅改票数的弹窗（不可换人）

## index_list 对应关系
```
index_list = [
  [15, 16, 17, 18, 19, 20, 21, 22],  // 16强上 → 可选人+改票数
  [7, 8, 9, 10],                       // 8强上 → 仅改票数
  [3, 4],                              // 4强上 → 仅改票数
  [1],                                 // 决赛上 → 仅改票数
  [0],                                 // 冠军   → 仅改票数
  [2],                                 // 决赛下 → 仅改票数
  [5, 6],                              // 4强下 → 仅改票数
  [11, 12, 13, 14],                    // 8强下 → 仅改票数
  [23, 24, 25, 26, 27, 28, 29, 30],   // 16强下 → 可选人+改票数
]
```

## 实现方案
1. 16强位置 (index 15-30)：`showSelector(index)` 弹出选人弹窗（现有逻辑，加票数输入）
2. 其余位置：新建 `showVoteEditor(index)` 弹出仅改票数的弹窗
3. 保存时 `num` 字段一起提交

## 验证标准
- 点击16强卡片 → 弹出选人弹窗，含票数输入框
- 点击其他卡片（有选手时）→ 弹出票数编辑弹窗，不可换人
- 点击其他卡片（空位时）→ 不做任何操作
- 保存时 num 字段正确传递
